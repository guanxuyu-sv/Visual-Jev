# Brand assets

- **Visual Jev**: original geometric V mark created for this project. The two strokes converge into a V for Visual / Victory. Copper `#C74E29`, graphite green `#1B2823`; light variant for dark surfaces. SVG is the editable master; PNG is a transparent export.
- **OpenAI**: unmodified Blossom assets from the [official logo archive](https://cdn.openai.com/brand/openai-logos.zip), retrieved November 18, 2026. [Brand guidelines](https://openai.com/brand/).
- **TypeSafe**: unmodified icon served by the [official website](https://typesafe.ai/): [source PNG](https://framerusercontent.com/images/aNFzSFxM4fjICmnibw7npfZjcQ.png), retrieved November 18, 2026.
